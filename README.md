# ScroomLab Updater Test

Canal public jetable utilisé exclusivement pour valider le mécanisme de mise à jour signé de ScroomLab.

- Aucun code source ScroomLab n'est publié ici.
- Aucun artefact de ce dépôt ne constitue une version publique de ScroomLab.
- Le canal de production reste séparé et inchangé.

Les installateurs portent des versions de prépublication `1.1.0-test.x` et sont destinés uniquement à une machine virtuelle de test.
